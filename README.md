# Mindful Meditation website

This is a responsive static website built from the supplied homepage screenshot, the supplied Mindful Meditation website content, and the latest navigation/content list.

## Files
- `index.html` — page structure and content
- `style.css` — black-and-white screenshot-inspired layout and responsive styling
- `script.js` — mobile navigation, demo login/signup, search, calendar and chatbot placeholder

## Preview
Open `index.html` in a browser, or use Visual Studio Code with the Live Server extension.

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` into the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish the site. The Pages settings screen will show the public URL.

## Before going live
- Replace `LOGO` with your real logo and update any text you want to personalise.
- Update the `hello@example.com` contact email.
- The login/signup form is only a front-end demonstration. Do not collect real passwords until you connect a secure authentication provider.
- Lesson booking, instructor discovery, AI chatbot, payments, customer reviews, shop and cancellation/refund handling are page sections/placeholders. Connect the relevant services and add your actual policies before using these features with customers.
- The sample photographs are loaded from Unsplash URLs and require an internet connection.
